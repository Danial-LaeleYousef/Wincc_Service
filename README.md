# WinCC Service Monitor

**WinCC Service Monitor** is a standalone **Windows executable (exe)** built with **Python and PyQt6**.  

It provides a **live overview of WinCC and related SQL services**, allowing you to **start, stop, and reset services** quickly and easily through a clean and user-friendly GUI.

---

## Key Features

- Live monitoring of WinCC and SQL services  
- Start / Stop service functionality  
- Reset WinCC with a single click  
- Ready-to-use **exe file**, no Python installation required  

---

## Built With

- Python  
- PyQt6  
- pywin32 (for Windows service management)  

---

## Usage

1. Download the **exe file** from GitHub.  
2. Run it with **Administrator rights**.  
3. Control services using the GUI buttons: Start, Stop, Reset.  

> Everything is bundled in a single executable—no setup needed.
